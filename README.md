# L6_L7_47_fuel_station

This repository contains the work completed for Lab 6 and Lab 7 as part of the Software Engineering and Testing course.

The repository focuses on different software testing techniques using a Python-based Fuel Station application.

## Repository Structure

### Lab 6 – Code Coverage and Branch Coverage
This lab focuses on measuring code coverage and branch coverage using pytest.

**Work completed:**
- Created test cases for the Fuel Station application.
- Achieved 100% code coverage.
- Achieved 100% branch coverage.
- Added screenshots documenting the test results.

### Lab 7 – Fuzz Testing
This lab focuses on identifying input validation bugs using fuzz testing and the Hypothesis library.

**Work completed:**
- Implemented property-based tests for three application functions.
- Used Hypothesis to generate unexpected inputs.
- Identified input validation issues.
- Improved the application by adding input validation.
- Successfully passed all three final fuzz-testing tests.
- Included screenshots and a combined PDF documenting the experiment.

## Technologies Used
- Python
- pytest
- pytest-cov
- Hypothesis
- Git and GitHub
- Visual Studio Code

## Purpose
The purpose of this repository is to demonstrate practical experience with software testing techniques, test case development, bug identification, input validation, and improving application reliability.
